# Working on this repo

- **Keep the Guide tab up to date.** Every change that adds or changes a user-visible feature must also update `src/pages/Guide.tsx` in the same commit: plain everyday words, and a live example built from the app's own components (made-up numbers, no working buttons).
- Push directly to `main` (the owner deploys from it via Netlify).
- Do not add automated tests unless asked.
- New features: describe them and get the owner's OK before building. Bug fixes can go straight in.
- The app never places orders and has no demo mode. Paid AI calls go through `netlify/lib/aiBudget.ts` (daily limit + cache); keep free rules ahead of AI calls.
- Phone-friendly is required: check a 390px-wide layout for any UI change.
- 🎚️ How careful (`src/lib/strictness.ts`): levels Careful / Balanced / Risky / Custom / Auto in `Settings.strictness` (+ `customRules`), synced. **Balanced = the original rules exactly** (checked against the old code on random data); keep it that way. Every BUY decision takes the resolved `Rules`: `analyze()` (trend.ts), `buyWait()`/`buyNotes()` (waitRules.ts), `isBuyIdea()` (picks.ts), the AI reviewer's strictness line (`AI_RULE`, reviewCore.ts), share sizing (`sizeQty`), the background check and "BUY is back on" (extraAlerts.ts). Auto resolves with the market (`resolveRules(settings, market)`). Locked at every level: no selling what you don't own, no buying on earnings day, no buying a downtrend with weak finances, never places orders. Score entries carry `level`.
- 📥 Fidelity import (`src/lib/fidelity.ts`, `src/components/FidelityImport.tsx`): the Positions .csv is read on the device (never uploaded); stocks/funds → holdings (same symbol across ticked accounts combined, weighted average), money-market (`**` symbols) → cash, options/bonds/pending skipped. A preview with tick boxes comes first; `boughtAt` dates are kept; stocks missing from the file are removed only if ticked. `Settings.importedAt` drives the "re-import after a trade" reminder (History toast + Today card).
- 🛑 Stop-loss watch (`src/lib/stopWatch.ts`, `Settings.stopWatch`, missing = on/10%/trailing): stop = the higher of "% below what you paid" and "% below the highest close since `boughtAt`" (trailing); per-stock %. Shown on Today tiles and in Settings; the hourly background check warns once (`checkStops` in extraAlerts.ts, `stopFired`, re-arms 3% above). Warning only, never an order.
- ☀️ Morning brief (`netlify/functions/brief.ts`, weekdays 13:05 UTC; `briefCore.ts`, `src/lib/brief.ts`, `Settings.morningBrief`, missing = on): market, last day, stops/price alerts within 3%, earnings ≤7 days, BUY now (same rules as the tiles). Free, no AI. Push + email + card on Today (`status.brief`).
- 🎯 Options helper (owner's choice "A", Ideas → 🎯 Options, `src/lib/options.ts`, `src/components/Options.tsx`, `netlify/functions/options.ts`): ideas to SELL covered calls (100+ shares, strike never below avg cost, contracts ≤ shares/100) and cash-secured puts (cash in Settings, watchlist stocks not in a downtrend); never naked, never an order: a copyable Fidelity ticket. Chain = Cboe delayed quotes (`cdn.cboe.com/api/global/delayed_quotes/options/SYM.json`, cached 10 min), else a Black–Scholes estimate from historical volatility, labelled "estimate". Level → `OPT_RULES` (delta 0.15/0.25/0.35, days, open interest, earnings avoid/warn; Custom = Balanced).
- 🌌 Look: "Quantum Terminal" (owner's request): deep #03060d background with slow glow orbs + faint grid (`.qt-bg` in App.tsx), glass `.card` with a thin glowing top edge, mono tabular `.num`, HUD `.label` (all in `src/index.css`). Phones/tablets: floating glass tab bar at the bottom with a sliding pill (`TabBar`, `src/components/Nav.tsx`, safe areas via `--qt-safe-top/bottom`, page room `.qt-main`); wide screens (lg+): `TopTabs` in the header. Semantic colours never change (green BUY/gain, red SELL/loss, amber WAIT, grey HOLD/SKIP, always with a word/arrow). Animate only transform/opacity; all motion off under `prefers-reduced-motion`.
- 🔮 What if tab (`src/pages/WhatIf.tsx`, `src/components/WhatIf.tsx`, `src/lib/whatif.ts` → `simulate`): back-test of "follow every BUY/SELL" on past daily closes (`/api/trends?range=2y`, + SPY), 3/6/12 months, amount, level (default = yours).
